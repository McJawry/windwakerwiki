# Welcome to the wiki

This is a **shared knowledge base** that anyone on the team can improve. Pages are stored as plain Markdown files in a GitHub repository, but you never have to touch Markdown — just click **Edit** and write, like in Notion.

> [!TIP]
> Press **Ctrl K** (or ⌘ K) to search every page, or type `[[` inside a page to link to another one.

## Where to start

- [[How to edit pages]] — a two-minute tour of the editor
- [[Getting started]] — setting up and publishing your own copy of this wiki
- [[Team handbook]] — an example of nested pages
- [[Style guide]] — keeping pages consistent

## Why a wiki?

Good notes stay useful when they are easy to **find**, easy to **link**, and easy to **fix**. Every page here keeps its full history in Git, so nothing is ever lost, and edits from people without write access arrive as pull requests that can be reviewed first.

<details>
<summary>Who can edit?</summary>

Anyone with a GitHub account. People with write access to the repository publish straight away; everyone else sends their edit as a pull request.

</details>
