# Style guide

Small habits that keep a shared wiki pleasant to read.

## Titles and structure

- Name pages for what people will *search* for, not for how you think about them.
- Start with one sentence that says what the page is for.
- Use headings freely — the outline on the right is built from them.

## Linking

Link generously with `[[Page title]]`. A red dashed link means the page doesn't exist yet; click it to create it. Pages that link here appear under **Linked from** at the bottom of each page, so you never need to maintain "see also" lists by hand.

## Keep it tidy

> [!WARNING]
> Never paste passwords, tokens, or private customer data into a page. The repository history keeps everything.

See also [[Team handbook]] and [[How to edit pages]].
